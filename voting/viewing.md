# Viewing Votes

Access the Voting Center from the drawer menu to browse all votes available to you.

## Accessing the Voting Center

1. Tap the **menu icon** (☰) in the top-left corner
2. Select **Voting Center** from the drawer menu
3. The Voting Center opens with tabbed navigation

## Vote Tabs

The Voting Center organizes votes into three tabs:

### Active Tab

Shows votes that are currently open for participation:

* **Votes accepting responses** - The voting period has started and not yet ended
* **Upcoming votes** - Published but the start time hasn't arrived yet
* **Awaiting manual start** - Published but waiting for a manager to start voting

Each vote card displays:

* Vote title and description
* Vote type badge (Ballot or Poll)
* Scope (Grand Chapter, Province, or Chapter)
* Time remaining or start time
* Your voting status (Voted / Not Yet Voted / Not Eligible)
* Participation count

### Completed Tab

Shows votes that have closed:

* Final results and participation statistics
* Your vote confirmation (if you participated)
* Winner/outcome indicators

### Drafts Tab _(Managers Only)_

Visible only to users with vote management permissions:

* Draft votes not yet published
* Options to edit, publish, or delete drafts

## Vote Card Information

Each vote card shows key information at a glance:

| Element | Description |
|---------|-------------|
| **Title** | The name of the vote |
| **Type Badge** | "Ballot" (anonymous) or "Poll" (non-anonymous) |
| **Scope** | Grand Chapter, Province, or Chapter name |
| **Status** | Active, Upcoming, Closed |
| **Time** | Time remaining or scheduled start |
| **Questions** | Number of questions in the vote |
| **Participation** | Number of votes cast / eligible voters |
| **Your Status** | Whether you've voted, can vote, or aren't eligible |

## Vote Detail Screen

Tap any vote card to open the full detail view:

* Complete vote description
* All questions with their options
* Eligibility requirements and your eligibility status
* Voting interface (if active and eligible)
* Results (if available)
* Participation statistics

## Eligibility Requirements

Some votes have eligibility requirements that must be met to participate:

* **Financial at Grand Chapter level** - Must be financially current nationally
* **Financial at Province level** - Must be financially current at the province level
* **Financial at Chapter level** - Must be financially current at the chapter level
* **Meeting check-in required** - Must have checked into a specific associated meeting

If you don't meet the requirements, the vote detail screen will show which requirements are not met.

## Weighted Votes

Some votes use weighted voting based on delegate lists:

* Your vote weight is determined by your delegate assignment
* If you are a proxy for other delegates, your vote carries their combined weight
* The vote detail screen shows your voting weight and any proxy assignments

## Refreshing Votes

Pull down on the vote list to refresh and load the latest votes.
