# Meeting Attachments

Meeting organizers and authorized users can upload and share documents, presentations, and other materials for meetings.

## Overview

Meeting attachments support the following document types:

| Category | Formats |
|----------|---------|
| **Documents** | PDF, Word (.doc, .docx) |
| **Spreadsheets** | Excel (.xls, .xlsx) |
| **Presentations** | PowerPoint (.ppt, .pptx) |
| **Images** | JPG, PNG, GIF, WebP, HEIC |
| **Videos** | MP4, MOV, AVI |

## Attachment Types

Attachments are categorized by type:

* **Agenda** - Meeting agenda documents
* **Minutes** - Meeting minutes and notes
* **Presentation** - Slide decks and visual materials
* **Handout** - Reference materials for attendees
* **Other** - Any other meeting-related documents

## Uploading Attachments

### During Meeting Creation

1. While creating a meeting, scroll to the **Attachments** section
2. Tap **Add Attachment**
3. Select a file from your device
4. The file is uploaded when the meeting is saved

### After Meeting Creation

1. Open the meeting detail screen
2. Switch to the **Attachments** tab
3. Tap the **Upload** button (if you have permission)
4. Select a file from your device
5. The file uploads and appears in the attachment list

## Viewing Attachments

1. Open the meeting detail screen
2. Switch to the **Attachments** tab
3. Browse the list of attached files

Each attachment shows:

* **File name**
* **File type** icon (PDF, Word, image, etc.)
* **File size**
* **Upload date**
* **Description** (if provided)

## Opening Attachments

Tap an attachment to view or download it:

* **In-app preview** is available for PDFs, Word documents, Excel files, PowerPoint presentations, and images
* **External app** opens for video files and unsupported formats
* Files are downloaded to your device for offline viewing

## Permissions

* **Meeting organizers** can upload and manage attachments
* **Authorized users** (based on role) can upload attachments
* **All invited attendees** can view and download attachments

## Best Practices

* Upload the meeting agenda before the meeting starts
* Add presentation materials so attendees can follow along
* Upload meeting minutes after the meeting concludes
* Use descriptive file names for easy identification
* Keep file sizes reasonable for mobile download (under 25MB recommended)
