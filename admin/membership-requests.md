# Managing Membership Requests

Chapter administrators can review and process requests from members who want to join their chapter.

## Overview

When a member requests to join your chapter (see [Joining a Chapter](../chapters/joining.md)), their request appears in your membership requests queue for review.

## Accessing Membership Requests

1. Navigate to **Chapter Settings**
2. Tap **Membership Requests**
3. View the list of pending, approved, and rejected requests

A badge on the Chapter Settings screen shows the count of **pending requests** awaiting review.

## Request Information

Each membership request displays:

* **Member name** and profile photo
* **Email address**
* **Current primary chapter** (the member's existing home chapter)
* **Requested membership type** - Primary (chapter transfer) or Associate
* **Reason** - The member's stated reason for joining
* **Submitted date**
* **Status** - Pending, Approved, or Rejected

## Reviewing Requests

### Approving a Request

1. Open the pending request
2. Review the member's information and reason
3. Tap **Approve**
4. Optionally add **review notes** (visible to the requesting member)
5. Confirm the approval

After approval:
* The member is added to your chapter's roster
* The member's chapter memberships update to show the new membership
* For primary transfers, the member's home chapter changes

### Rejecting a Request

1. Open the pending request
2. Review the member's information and reason
3. Tap **Reject**
4. Optionally add **review notes** explaining the rejection (visible to the requesting member)
5. Confirm the rejection

After rejection:
* The member's request status changes to "Rejected"
* They can see the review notes for the rejection
* They can submit a new request in the future if circumstances change

## Filtering Requests

Filter the request list by status:

* **Pending** - Requests awaiting your review
* **Approved** - Previously approved requests
* **Rejected** - Previously rejected requests

## Best Practices

* Review pending requests promptly to provide a good member experience
* Include review notes when rejecting a request so the member understands why
* Verify the member's identity and standing before approving
* For primary chapter transfers, coordinate with the member's current chapter if needed
