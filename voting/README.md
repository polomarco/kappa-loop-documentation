# Voting Center

The Voting Center allows fraternity members to participate in formal votes and polls at the chapter, province, and national levels.

## Overview

The Voting Center supports two types of votes:

* **Ballots** - Anonymous voting for formal organizational decisions. Individual votes cannot be traced back to voters.
* **Polls** - Non-anonymous feedback collection where vote choices are visible to managers.

## Key Features

* **Multiple Question Support** - A single vote can contain multiple questions, each with its own option type
* **Flexible Option Types** - Single choice, multiple choice, or Yes/No/Abstain
* **Eligibility Controls** - Financial standing requirements, meeting check-in requirements, and manual overrides
* **Weighted Voting** - Delegate-based voting with configurable vote weights and proxy support
* **Real-time or Closed Results** - Configure whether results are shown during voting or only after closing
* **Results Visibility** - Results can be visible to everyone or managers only
* **Start Modes** - Scheduled, immediate, or manual start options

## Vote Scopes

Votes are scoped to specific organizational levels:

* **Grand Chapter (National)** - Organization-wide votes
* **Province** - Regional-level votes
* **Chapter** - Chapter-level votes

## Vote Statuses

* **Draft** - Created but not yet published (only visible to managers)
* **Active** - Published and accepting votes
* **Closed** - Voting period has ended
* **Cancelled** - Vote was cancelled by a manager

## Quick Actions

| Action | Description |
|--------|-------------|
| View active votes | See votes currently open for participation |
| Cast your vote | Submit your selections for an active vote |
| View results | See vote outcomes after voting closes |
| Create a vote | Start a new ballot or poll _(Managers only)_ |
| Manage eligible voters | Add or remove eligible participants _(Managers only)_ |
