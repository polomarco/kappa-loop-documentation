# User Permissions

Manage detailed content creation and management permissions for individual users.

## Overview

The user permissions screen allows administrators to view and configure granular permissions for content management operations.

## Accessing User Permissions

1. Navigate to the appropriate settings screen (National, Province, or Chapter)
2. Tap **User Permissions**

## Permission Categories

Permissions are grouped by content type:

### Announcement Permissions
* Create announcements
* Edit announcements
* Delete announcements
* Pin/unpin announcements

### Event Permissions
* Create events
* Edit events
* Delete events

### Vote Permissions
* Create votes
* Manage votes
* View vote results
* Manage eligible voters

### Meeting Permissions
* Create meetings
* Manage attendance
* Upload attachments
* Export attendance records

## Viewing Permissions

The permissions screen shows:

* List of users with assigned permissions
* Each user's active permissions grouped by category
* The scope at which permissions are granted

## How Permissions Are Granted

Permissions are typically granted through **Role Assignment** (see [Role Assignment](role-assignment.md)). The user permissions screen provides a detailed view of what each role includes and allows fine-grained adjustments when needed.
