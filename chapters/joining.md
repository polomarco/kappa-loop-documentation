# Joining a Chapter

You can request to join a chapter through the Browse Chapters directory.

## How to Submit a Join Request

1. Navigate to the chapter you want to join (via **Browse Chapters**)
2. Open the chapter detail screen
3. Tap the **Join Chapter** button
4. Fill out the join request form

## Join Request Form

When requesting to join a chapter, you'll provide:

* **Reason** _(required)_ - Explain why you'd like to join this chapter

## Request Approval Process

After submitting a request:

1. Your request appears as **Pending**
2. Chapter managers receive a notification about the new request
3. A chapter manager reviews your request
4. The manager can **Approve** or **Reject** the request

### Approval

If approved:
* Your new chapter membership is activated

### Rejection

If rejected:
* The request status changes to "Rejected"
* Review notes from the manager may be provided
* You can submit a new request if circumstances change

## Viewing Request Status

Request statuses:

* **Pending** - Awaiting review by a chapter manager
* **Approved** - Your membership has been granted
* **Rejected** - Your request was declined (check review notes for details)

## Troubleshooting

### Join Button Not Visible

* You may already be a member of this chapter
* You may have a pending request for this chapter
* Check your existing chapter memberships

### Request Taking Too Long

* Requests require manual review by a chapter manager
* Contact the chapter's Polemarch or Keeper of Records if your request hasn't been reviewed
