# Administration

Kappa Loop provides administrative tools for managing officers, roles, permissions, and organizational settings at the national, province, and chapter levels.

## Overview

Administrative features are role-based and vary depending on your organizational position:

* **National Administrators** - Manage national officers, settings, and permissions
* **Province Administrators** - Manage regional settings and permissions
* **Chapter Administrators** - Manage chapter settings and permissions

## Key Features

* **Officer Management** - Assign and manage officer titles and positions
* **Role Assignment** - Grant and revoke management roles and permissions
* **Settings Management** - Configure organizational settings at each level
* **User Permissions** - Manage content creation and management permissions

## Accessing Admin Features

Admin features are available through the drawer menu (☰) on each organizational screen:

* **Manage Grand Chapter** - Available on the Grand Chapter (National) screen
* **Manage Province** - Available on the Province screen
* **Manage Chapter** - Available on the Chapter screen

These options are only visible to users with the appropriate administrative roles.
